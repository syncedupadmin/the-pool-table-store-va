# The Pool Table Store demo

Standalone Next.js 16 App Router demonstration for The Pool Table Store, Alexandria, Virginia.

## Verified content boundary

Content is based on the official public pages at:

- https://www.thepooltablestoreva.com/
- https://www.thepooltablestoreva.com/services
- https://www.thepooltablestoreva.com/contact

Primary action is phone/text: `+1 571 236 2119`. The secondary number `+1 703 721 9740` is omitted from the primary conversion path because it appears only on an alternate official page and directory listings.

## Local commands

```powershell
npm install
npm run typecheck
npm run lint
npm run build
npm run qa
```

This demo includes `noindex` metadata, `robots.txt` disallow rules, a generated 1200×630 OG image, and an icon route. It has not been connected to GitHub, Vercel, DNS, or production booking systems.
